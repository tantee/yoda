ใส่รหัสติดตั้งเพื่อเริ่มตั้งค่า

รหัสนี้พิสูจน์ว่าคุณเป็นผู้ดูแลเครื่องที่ติดตั้ง Yoda รหัสแสดงอยู่ใน log ของ container core เท่านั้น

ABCDEFGHJKLMNP····
วางทั้งรหัสได้ในช่องแรก ไม่ต้องสนใจตัวพิมพ์เล็กใหญ่ รหัสใช้ได้ครั้งเดียว และหมดอายุใน 24 ชั่วโมง
หารหัสได้ที่ไหน
  1. บนเครื่องที่ติดตั้ง ในโฟลเดอร์ /srv/yoda พิมพ์คำสั่งนี้
$ docker compose exec core yoda-admin setup-token ┌─ Yoda setup ────────────────────────────── │ Open /setup on the portal and enter this token: │ ABCD-EFGH-JKLM-NPQR-STUV │ Expires in 23 h 41 min · changes when core restarts └───────────────────────────────────────────
  1. หรือดูใน log: docker compose logs core | grep -A3 "Yoda setup"
การเชื่อมต่อนี้ไม่ได้เข้ารหัส (http)
รหัสติดตั้งจะถูกส่งผ่านเครือข่ายแบบไม่เข้ารหัส แนะนำให้เปิดผ่าน reverse proxy ที่เป็น https หรือผ่าน SSH tunnel: ssh -L 3000:127.0.0.1:3000 yoda-host
ใส่รหัสผิดได้ 5 ครั้งต่อ 15 นาที

ระบบนี้ยังไม่ได้ตั้งค่า หน้านี้จะหายไปเมื่อการติดตั้งเสร็จ
